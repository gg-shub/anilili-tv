## About

Anilili TV is a native Android anime streaming client optimized specifically for Android TV and Google TV devices. It offers a modern Material 3 interface with full D-pad remote support, making browsing fast and intuitive.

## Highlights

- **Seamless Sync:** Metadata, user login, library lists, and watch progress are synced seamlessly via AniList and MyAnimeList.
- **Extensive Sources:** Resolves episodes and streams from multiple providers, including Miruro, AniKoto, ReAnime, AniZone, AnimeGG, AniNeko, and 2DHive.
- **Native Playback:** HLS streams are handled smoothly by ExoPlayer, with WebView support for embed providers and fallback playback.
- **On-Device Decoding:** Miruro streams are securely requested through the Miruro pipe endpoint and decoded right on your device. Other sources resolve via the Anivexa-backed provider client.
